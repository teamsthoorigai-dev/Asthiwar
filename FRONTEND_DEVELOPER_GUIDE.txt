1. PROJECT ARCHITECTURE & REPOSITORY SETUP
================================================================================

The repository is structured as a monorepo containing:
- /web      : Next.js (App Router), TypeScript, Vanilla / CSS Modules
- /backend  : Node.js, Express, TypeScript REST API, PDFKit generator
- /database : Drizzle ORM, PostgreSQL (Neon), migrations, and seeds
- /docs     : Architecture specs, flow documentation, and changelogs

Local Setup Commands:
---------------------
1. Clone / Pull Repository:
   git clone https://github.com/teamsthoorigai-dev/Asthiwar.git
   git checkout dev
   git pull origin dev

2. Install Dependencies (from project root):
   npm install

3. Run Development Servers:
   Frontend (Next.js) : npm run dev:frontend (or cd web && npm run dev) -> http://localhost:3000
   Backend (Express)  : npm run dev:backend  (or cd backend && npm run dev) -> http://localhost:4000

4. Environment Variables:
   Frontend (`web/.env.local`):
     NEXT_PUBLIC_API_URL=http://localhost:4000

3. KEY BUSINESS & ARCHITECTURAL RULES (LATEST UPDATES)
================================================================================

A. Package-Specific Brand Pricing:
   - Each brand specification (e.g. UltraTech Cement, Tata Tiscon Steel, Kohler Fixtures)
     maintains independent rate definitions across all 4 tiers:
     * Basic (Tier 1)
     * Standard (Tier 2)
     * Premium (Tier 3)
     * Luxury (Tier 4)
   - Rates (`priceDelta`):
     * 0.00  -> "Included" (no surcharge).
     * > 0   -> "+Rs.{priceDelta}/sqft" (upgrade surcharge).
     * < 0   -> "-Rs.{abs(priceDelta)}/sqft (Credit)" (downgrade credit).

B. 11 Standard Construction Exclusions (Step 5 & PDF Quote):
   The following 11 items are strictly classified as Client Scope / Excluded from the
   standard civil construction contract and must be visible on Step 5:
   1. Elevation Work (Architectural facade claddings beyond standard design)
   2. Outer Area Development (Setbacks, perimeter pavers, compound pathways, landscaping)
   3. Interior Works & Carpentry (Wardrobes, modular kitchen, loose furniture)
   4. Building Plan Sanction (DTCP / Local body building approval & liaison fees)
   5. Electricity Board / EB (Permanent line connection, meter deposit & statutory tariffs)
   6. Gas Connection (Piped gas line connection & municipal installation)
   7. Water & Drainage / UGD (Municipal drinking water & underground drainage fees)
   8. Borewell Drilling (Borewell drilling, PVC casing pipe & depth piping)
   9. Water Motors & Pumps (Supply/installation of pumps unless chosen in Add-Ons)
   10. Electrical Appliances (TV, Refrigerator, ACs, Chimney, Hob, Geysers)
   11. Taxes & Levies (Vacant Land Tax / VLT, property taxes, municipal duties)

C. Dynamic Add-On Rules (Roof Weathering / Cool Roof Tiles):
   - Premium & Luxury Packages: Roof Weathering is automatically Rs.0 (Included).
   - Basic & Standard Packages: If terrace area > 2,000 sq.ft, weathering is waived (Rs.0).
     Otherwise billed at Rs.65/sq.ft of terrace area.

D. Package Taglines:
   - Basic    : "Essential"
   - Standard : "Comfort"
   - Premium  : "Best Value" (Strictly updated to "Best Value")
   - Luxury   : "Ultimate Luxury"

E. Dimension Microcopy:
   - Display note under Car Parking Area:
     "Note: Only if parking is separate from the floor built-up area above."

5. STEP-BY-STEP CALCULATOR WIZARD & LOGIC RULES
================================================================================

Step 1: Dimensions
- Capture Plot Area (sq.ft) and Built-up Area per floor.
- Total Built-Up Area = Sum of Floor Built-up Areas + Balcony Area.
- Total Construction Area = Total Built-Up Area + Car Parking Area.

Step 2: Add-Ons & Utilities
- Water Sump & Septic Tank (Capacity in Litres, RCC/Brick/Readymade).
- Compound Wall (Running Feet & Height).
- Motor Automation (Bore OHT Rs.12k, Corp OHT Rs.12k, Both Rs.24k).
- Pressure Pump (0.5 HP, 1.0 HP, 1.5 HP, 2.0 HP).
- Water Softener (AO Smith Automatic Whole-house Rs.1,05,000).
- Solar Rooftop (3kW to 10kW On-Grid/Hybrid).

Step 3: Package Selection
- Basic, Standard, Premium, Luxury cards.
- Live dynamic subtotal calculation per card.
- "Best Value" highlight badge on Premium Package.

Step 4: Brand Customizations
- Specification items rendered under Category accordions.
- Badges:
  * priceDelta === 0 -> "Included" (emerald badge).
  * priceDelta > 0   -> "+Rs.{priceDelta}/sqft" (accent badge).
  * priceDelta < 0   -> "-Rs.{abs(priceDelta)}/sqft (Credit)".

Step 5: Estimate Report & PDF Download
- Breakdown: Base Construction + Brand Deltas + Utilities/Add-Ons = Grand Total.
- 10 Construction Milestone Schedule with payment percentages.
- 11 Standard Exclusions & Client Scope cards.
- Instant Lead Capture modal & Instant PDF Quote download.

6. ADMIN PORTAL CONFIGURATION GUIDE
================================================================================

Component: `AdminPricingConfigManager.tsx`
- Free vs Upgrade Toggle:
  * When `isComplimentary` is true or `priceDelta === 0`: Shows "v Free" button.
  * Clicking "v Free" switches into custom input (e.g. Rs.45).
  * Clicking "x" resets back to "v Free" (0.00).
- Batch Submission Contract:
  PUT /api/admin/config/options/:optionId/price
  Payload:
  {
    "prices": [
      { "packageId": "pkg-1", "priceDelta": 45.00, "isComplimentary": false },
      { "packageId": "pkg-2", "priceDelta": 20.00, "isComplimentary": false },
      { "packageId": "pkg-3", "priceDelta": 0.00,  "isComplimentary": true },
      { "packageId": "pkg-4", "priceDelta": 0.00,  "isComplimentary": true }
    ]
  }

7. BACKEND API ENDPOINTS & CONTRACT REFERENCE
================================================================================

Base URL: `http://localhost:4000/api`

1. GET `/api/calculator/config`
   - Fetches active packages, specification categories, default brand options, and addon rates.

2. POST `/api/calculator/calculate`
   - Request Body:
     {
       "packageId": "uuid",
       "dimensions": {
         "plotArea": 1200,
         "floors": [{ "floorNumber": 0, "builtUpArea": 900 }, { "floorNumber": 1, "builtUpArea": 850 }],
         "parkingArea": 200,
         "balconyArea": 100
       },
       "customizations": [{ "categoryId": "uuid", "optionId": "uuid" }],
       "addons": [{ "addonId": "uuid", "quantity": 1, "parameters": { "capacity": 6000 } }]
     }
   - Returns: `baseCost`, `customizationsCost`, `addonsCost`, `subtotal`, `grandTotal`, and `milestones`.

3. POST `/api/calculator/submit-lead`
   - Submits customer lead with estimation state snapshot and generates downloadable PDF link.

4. GET `/api/admin/config`
   - Returns master packages, base rates, addons, and 4-tier brand specification matrix.

5. PUT `/api/admin/config/options/:optionId/price`
   - Updates all 4 package price deltas for a brand option.

================================================================================

1. Currency Formatting (INR):
   ```typescript
   export const formatINR = (val: number): string =>
     new Intl.NumberFormat('en-IN', {
       style: 'currency',
       currency: 'INR',
       maximumFractionDigits: 0
     }).format(val);
   ```

2. Design Standards:
   - Primary Accent : Deep Indigo / Emerald / Slate tones
   - Included Badge : Emerald Green (#10B981 / #059669)
   - Upgrade Badge  : Blue / Indigo (#3B82F6 / #6366F1)
   - Credit Badge   : Amber / Orange (#F59E0B)
