1. PROJECT OVERVIEW & REPOSITORY SETUP
================================================================================

The Asthiwar web application comprises:
- Public Cost Calculator (5-step progressive estimation wizard)
- Marketing & Services Pages (Home, Services, Projects, Portfolio)
- Admin Portal (Leads management, dynamic pricing matrix, brand configs)
- Backend API (Node.js / Express / TypeScript / Drizzle ORM / PostgreSQL)

Local Setup Commands:
---------------------
1. Clone / Pull Repository:
   git clone https://github.com/teamsthoorigai-dev/Asthiwar.git
   git checkout dev
   git pull origin dev

2. Install Dependencies:
   npm install

3. Run Development Servers:
   Frontend: npm run dev:frontend (or cd web && npm run dev)
   Backend : npm run dev:backend  (or cd backend && npm run dev)

4. Environment Variables:
   Frontend (.env.local / .env):
     NEXT_PUBLIC_API_URL=http://localhost:4000
     (or VITE_API_URL=http://localhost:4000 depending on client bundler)

2. KEY ARCHITECTURAL UPDATES (LATEST CHANGES - 2026-09-03)
================================================================================

A. Brand Customisation Pricing Architecture
-------------------------------------------
- Every brand specification option now has distinct, package-specific pricing
  for each of the 4 tiers: Basic (1), Standard (2), Premium (3), Luxury (4).
- Price Deltas (priceDelta) can be:
  * 0.00  -> Complimentary / Included with the package.
  * > 0   -> Upgrade surcharge per sq.ft (e.g., +Rs.45/sq.ft).
  * < 0   -> Downgrade credit per sq.ft (e.g., -Rs.20/sq.ft Credit).
- Backend now joins `option_prices` directly by packageId. There are no generic
  or ambiguous fallback prices.

B. 11 Standard Construction Exclusions (Step 5 & Contract Scope)
----------------------------------------------------------------
To ensure full transparency before contract signing, the Step 5 estimate report
and the generated PDF explicitly list the 11 client-scope items:
  1. Elevation Work (Architectural facade claddings beyond standard design)
  2. Outer Area Development (Setbacks, pavers, compound pathways, landscaping)
  3. Interior Works & Carpentry (Wardrobes, modular kitchen, loose furniture)
  4. Building Plan Sanction (DTCP / Local body building approval liaison fees)
  5. Electricity Board / EB (Permanent line connection, meter deposit & tariffs)
  6. Gas Connection (Piped gas connection & pipeline installation)
  7. Water & Drainage / UGD (Municipal drinking water & underground sewer fees)
  8. Borewell Drilling (Borewell drilling, casing pipe & submersible piping)
  9. Water Motors & Pumps (Pumps/motors supply unless selected in Add-Ons)
  10. Electrical Appliances (TV, Refrigerator, ACs, Chimney, Hob, Geysers)
  11. Taxes & Levies (Vacant Land Tax / VLT, property taxes, municipal duties)

C. Dynamic Add-On Rules (Roof Weathering / Cool Roof Tiles)
-----------------------------------------------------------
- Premium & Luxury Packages: Roof Weathering is automatically Rs.0 (Included).
- Basic & Standard Packages: If terrace area > 2,000 sq.ft, weathering is waived
  (Rs.0). Otherwise, it is billed at Rs.65/sq.ft of terrace area.

D. Package Naming & Taglines
----------------------------
- Basic   : "Essential"
- Standard: "Comfort"
- Premium : "Best Value" (Note: Tagline strictly updated to "Best Value")
- Luxury  : "Ultimate Luxury"

E. Dimension Microcopy
----------------------
- Under "Car Parking Area (Sq.Ft)", always display the microcopy note:
  "Note: Only if parking is separate from the floor built-up area above."

3. STEP-BY-STEP CALCULATOR FLOW & UI RULES
================================================================================

Step 1: Project Type & Built-up Dimensions
------------------------------------------
- Inputs:
  * Plot Area (sq.ft)
  * Number of Floors (Ground, G+1, G+2, G+3, etc.)
  * Built-up Area per floor (sq.ft)
  * Car Parking Area (sq.ft) [Optional]
  * Balcony / Utility Area (sq.ft) [Optional]
- Total Built-Up Area = Sum of Floor Areas + Balcony/Utility Area.
- Total Construction Area = Total Built-Up Area + Car Parking Area.

Step 2: Add-Ons & Utilities Selection
-------------------------------------
- Add-on Categories:
  * Water Sump (R.C.C / Brick / Readymade) -> Capacity in Litres
  * Septic Tank (R.C.C / Brick / Readymade) -> Capacity in Litres
  * Compound Wall -> Running Feet & Height
  * Motor Automation -> Bore OHT (Rs.12k), Corp OHT (Rs.12k), Both (Rs.24k)
  * Pressure Pump -> 0.5 HP, 1.0 HP, 1.5 HP, 2.0 HP variants
  * Water Softener -> Whole House RO / Automatic Softener (AO Smith Rs.1.05L)
  * Solar Rooftop System -> 3kW, 5kW, 8kW, 10kW On-Grid / Hybrid
  * EV Charging Provision -> 3.3kW / 7.2kW AC Fast Charger
  * Rainwater Harvesting Pit -> Standard Recharge Pit

Step 3: Construction Package Selection
--------------------------------------
- Cards displaying 4 tiers: Basic, Standard, Premium, Luxury.
- Display base price per sq.ft (e.g. Rs.1,890, Rs.2,190, Rs.2,490, Rs.2,990).
- Highlight "Best Value" badge on the Premium Package card.
- Show live computed subtotal for each package card dynamically.

Step 4: Brand & Material Customizations
---------------------------------------
- Grouped by specification categories:
  * Structure & Steel (e.g. Tata Tiscon, JSW Neosteel, Kamachi)
  * Cement (e.g. UltraTech, Coromandel, Ramco Supergrade)
  * Flooring & Tiles (e.g. Kajaria, Somany, Nitco)
  * Bathroom Fixtures & Sanitaryware (e.g. Kohler, Jaquar, Parryware)
  * Electrical Cables & Switches (e.g. Legrand, Schneider, Havells, Finolex)
  * Painting & Finishes (e.g. Asian Paints Royale, Berger, Dulux)
- UI Badge Rules:
  * If priceDelta === 0 -> Render badge: "Included" (emerald/green).
  * If priceDelta > 0   -> Render badge: "+Rs.{priceDelta}/sqft" (blue/neutral).
  * If priceDelta < 0   -> Render badge: "-Rs.{abs(priceDelta)}/sqft (Credit)".

Step 5: Estimate Report & PDF Download
--------------------------------------
- High-level cost breakdown summary:
  * Civil & Construction Cost
  * Customizations Upgrade / Delta Cost
  * Add-Ons & Utilities Cost
  * GST / Statutory Subtotal (if applicable)
  * Grand Total (INR)
- 10 Construction Milestone Schedule with payment percentages.
- 11 Standard Exclusions & Client Scope cards.
- Instant Lead Capture & Instant PDF Quote Generation button.

4. ADMIN PORTAL CONFIGURATION GUIDE
================================================================================

Component: AdminPricingConfigManager.tsx
---------------------------------------
1. Inline Brand Table & Add-Brand Modal:
   - When viewing or editing brand options, display 4 responsive tier cards:
     [Basic] [Standard] [Premium] [Luxury]
   - "Free / Upgrade" State Handling:
     * When isComplimentary is true or delta === 0:
       Render button: "v Free"
     * Clicking "v Free" reveals number input to set custom rate (e.g. Rs.45).
     * Clicking "x" icon clears rate and sets back to "v Free" (0.00).

2. Batch Price Payload Format:
   When submitting brand option pricing updates, the frontend sends:
   {
     "prices": [
       { "packageId": "pkg-basic-uuid",    "priceDelta": 50.00, "isComplimentary": false },
       { "packageId": "pkg-standard-uuid", "priceDelta": 25.00, "isComplimentary": false },
       { "packageId": "pkg-premium-uuid",  "priceDelta": 0.00,  "isComplimentary": true },
       { "packageId": "pkg-luxury-uuid",   "priceDelta": 0.00,  "isComplimentary": true }
     ]
   }

5. API ENDPOINTS & CONTRACT REFERENCE
================================================================================

Base URL: http://localhost:4000/api (or process.env.NEXT_PUBLIC_API_URL + '/api')

A. Calculator Endpoints:
------------------------
1. GET /api/calculator/config
   - Returns packages, categories, default specifications, and active add-on rates.
   - Use to bootstrap wizard state on initial load.

2. POST /api/calculator/calculate
   - Request Body:
     {
       "packageId": "uuid",
       "dimensions": {
         "plotArea": 1200,
         "floors": [
           { "floorNumber": 0, "builtUpArea": 900 },
           { "floorNumber": 1, "builtUpArea": 850 }
         ],
         "parkingArea": 200,
         "balconyArea": 100
       },
       "customizations": [
         { "categoryId": "uuid", "optionId": "uuid" }
       ],
       "addons": [
         { "addonId": "uuid", "quantity": 1, "parameters": { "capacity": 6000 } }
       ]
     }
   - Response:
     {
       "success": true,
       "data": {
         "baseCost": 3723000,
         "customizationsCost": 42500,
         "addonsCost": 285000,
         "subtotal": 4050500,
         "taxAmount": 0,
         "grandTotal": 4050500,
         "milestones": [
           { "stage": 1, "title": "Mobilization & Foundation", "percentage": 15, "amount": 607575 },
           ...
         ]
       }
     }

3. POST /api/calculator/submit-lead
   - Request Body:
     {
       "customerName": "Ramesh Kumar",
       "phone": "9876543210",
       "email": "ramesh@example.com",
       "city": "Chennai",
       "calculationState": { ...full calculate payload + results... }
     }
   - Response:
     {
       "success": true,
       "data": {
         "leadId": "lead-uuid",
         "pdfUrl": "/api/admin/leads/lead-uuid/pdf"
       }
     }

4. GET /api/calculator/catalog
   - Returns full catalog grouped by specification category with all 4 tier prices.

B. Admin Configuration Endpoints:
---------------------------------
1. GET /api/admin/config
   - Requires Admin Auth Bearer token.
   - Returns all master packages, base rates, addons, and brand specification matrix.

2. PUT /api/admin/config/options/:optionId/price
   - Updates all 4 package price deltas for a specific brand option.
   - Request Body: { "prices": [ { "packageId": "...", "priceDelta": 0, "isComplimentary": true }, ... ] }

3. POST /api/admin/config/options
   - Creates a new brand option and its 4 package rate definitions simultaneously.

4. DELETE /api/admin/config/options/:optionId
   - Deletes brand option and associated price deltas.

6. COMPONENT & STYLING GUIDELINES
================================================================================

1. Currency Formatting:
   - Always format INR figures using Indian numbering format:
     const formatINR = (val: number) =>
       new Intl.NumberFormat('en-IN', {
         style: 'currency',
         currency: 'INR',
         maximumFractionDigits: 0
       }).format(val);
   - Examples: Rs.1,890 / sq.ft, Rs.45,50,000

2. Responsive Design:
   - Wizard steps must be 100% mobile-friendly with thumb-friendly radio cards.
   - Sticky Bottom Bar on mobile to display current package, estimated total, and
     "Continue / Download Estimate" call-to-action button.

3. Color Scheme & Token Standards:
   - Primary Accent : Deep Indigo / Emerald / Slate tones
   - Success / Free : Emerald Green (#10B981 / #059669)
   - Backgrounds    : Clean card elevations, dark/light theme compatible
